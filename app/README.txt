TDS Macro - Windows v0.5.2

Run TDSMacro.exe from the entire extracted folder. Keep _internal,
assets, calibrations, strategies, docs and notices together.

Read docs/setup.md and docs/requirements/strategies/README.md before
starting. These explain the tested account, cash, display and loadout
conditions. The macro does not guarantee compatibility with every
account, skill combination, avatar or later game update.

SUPPORTED SOLO STRATEGIES

Golden Scout - 10 Max (Dead Ahead / Easy)
  Slot 1: Scout with active Golden perk. Slots 2-5: empty.
  Ten placements and forty guarded E upgrades; ten level-4 Scouts.
  Same positively confirmed tower selection can be reused.
  Credit requires a verified full strategy, wave-20 Victory and
  readable Coin reward.

Golden Scout - 9 legacy fallback (Dead Ahead / Easy)
  Same loadout, 44 actions. Eight level-4 Scouts and one level-3 Scout.
  Retains the older calibrated mouse-upgrade path.

Hardcore Gem Grind (Wretched Front / Hardcore)
  Slots 1-3: Boomerang, regular Crook Boss, Farm. Slots 4-5: empty.
  Four pre-Ready Farms require at least $1,200 live starting cash.
  Credit requires the verified natural wave-30 Defeat with 137
  displayed Gems and the required strategy evidence.

Hardcore Gems + Tower XP
  Same slots 1-3; supported XP tower in slot 4; slot 5 empty.
  Optional X1 is level 0 at the calibrated central point (976,580).
  It needs a verified live price from $200 to $10,000, verified
  critical defense, and enough cash AFTER reserving the next verified
  core-upgrade quote. Expensive XP towers may remain unplaced.
  Gem credit and verified XP-tower placement are separate counters;
  placement alone does not prove a numerical Tower XP reward.

OPERATION

Equip the exact ordered loadout manually; Auto-Equip is disabled.
Use Windows 11, the official Store Roblox GDK client, English TDS,
1920x991 physical client pixels at 120 DPI, Large UI and vertical
upgrades, normal 1x speed, supported camera and foreground window.

Select the matching strategy in Run setup. Start / F1 starts the
guarded worker. F2 stops safely; F8 or Escape stops immediately.
Do not send competing inputs or change foreground during play.

Continuous mode separates successful credit from recovery. A complete
uncredited result may safely restart with a verified result control.
The candidate allows up to two direct replays and three guarded
client relaunches without a new credited result. Client relaunch
requires the recovery option. Explicit stops, persistent focus loss,
changed client, invalid setup, unsafe terrain, low storage and
exhausted recovery budget stop safely. Unknown or unconfirmed paid
actions are never repeated. Coins and Gems are result-screen totals,
not an independent account-wallet audit.

Diagnostics and Updates are separate dashboard windows. Automatic
updates are OFF by default. Verified stable updates install only
while idle, preserve the previous installation and start the GUI
without automatically resuming gameplay.

Private logs and captures are kept locally in captures/runs.
Do not publish raw account screenshots, logs or credentials.

See docs/APP.md, docs/troubleshooting.md and docs/verification.md.
Loadout switching and strategy rotation are future v1.0 plans,
not features in this version.
