- Keep active install, one verified last-good rollback and official digest-verified ZIP or verified redownload route. Stage new release separately with checksum, archive/path/privacy checks and self-check; update idle only after verified prior process exit.

No recursion through junctions or deleting active/unknown directories. Test interrupted swap, failed verification/launch, locked files, rollback, stale staging and cleanup exclusions.
