# v0.4.0 — Opt-in verified Windows auto-update

Scope: update the packaged Tk GUI, not the Roblox input controller.
The public v0.3.4 assets, original strategy and route remain unchanged.

## User controls
- Updates tab: persistent Automatic updates ON/OFF (default OFF).
- Check now: inspect official stable release metadata without installing.
- Download update: fetch and verify only when gameplay worker is idle.
- Install verified update: hand off to the frozen staged helper; GUI restarts idle.
- Enabled mode checks at startup and every six hours; automatically prepares
  and installs an available update only while worker is not running.

## Trust and failure boundaries
- Exact PracticalSwan/TDSMacro GitHub release path and numeric stable tag.
- GitHub asset digest, checksum asset digest and SHA256SUMS must match.
- ZIP file paths, case collisions, symlinks, total sizes and embedded app
  version are validated before extraction.
- Frozen candidate self-check must pass before installation.
- Full staged app-tree integrity is rechecked before any file replacement.
- Helper waits for the old GUI to exit; preserves the entire old folder
  and its local captures as a timestamped backup.
- Failed second rename must roll back. No forced Roblox/gameplay stop,
  paid-action replay, automatic match resumption or repeated install loop.
- All updater network work runs off Tk's event thread.

## Release gate (no partial release)
1. Source unit and regression tests, including updater negative paths.
2. Windows hosted CI and local frozen self-check/version verification.
3. Disposable dummy-install transaction, failure rollback and preservation.
4. GUI visual/click smoke for Update ON/OFF, manual check, idle gating.
5. Native full Wretched Front Hardcore Solo result and direct Restart Match
   with the unchanged three-tower loadout and single input worker.
6. ZIP CRC, published SHA256SUMS/digest, no private user files.
7. Commit/push, publish new immutable v0.4.0 tag, re-download and verify.
8. Keep historical v0.3.4 install and local experimental calibration.
