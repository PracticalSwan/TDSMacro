**Goal:** Add a second, isolated, reliable Solo Hardcore Wretched Front strategy that places Boomerang, regular Crook Boss and Farm in fixed slots; skips waves; aims for a wave-29/30 intentional loss; verifies credited gems; and repeats, while preserving the released v0.2.4 Golden Scout strategy.

**Status:** Planning only as of 2026-11-18 (Asia/Bangkok). Nothing in this plan is implemented or live-verified for Hardcore. Only the v0.2.4 Golden Scout mode is currently published. ## Product behavior and user-facing decisions

1. GUI must show exactly two available strategy labels after the Hardcore one is accepted; old Golden Scout is selected by default on a fresh install. Choosing Hardcore displays Wretched Front, required slots, normal speed default, auto-recovery, current phase, confirmed gems/cycles, elapsed time and last stop reason. Coin/win totals remain scoped to Golden Scout and must not be added to gems.
2. No user account/tower ownership API: use only live inventory/hotbar observations; if required tower missing or a slot mismatched, report an actionable stop reason and do not send game input. Optional slot 4 can be empty; an equipped, visually identified fourth tower may receive one placement at wave 22 if terrain allows, otherwise record a nonfatal skip. The first profile requires empty slot 5.
3. Default strategy uses continuous auto-skip as far as the UI actually permits, with visual confirmation that the configured skip state is active. If UI offers only per-wave Skip, send at most one guarded click per positively verified eligible wave and recheck the resulting state; never click based only on timers.
4. No unrestricted resume in the middle of a wave after an unknown purchase, reconnect, foreground loss or client change. Recovery always restarts at a fresh lobby/map and an empty tower ledger, counting separately from intentional defeats. Do not interpret normal Hardcore defeat as a failed game or spend the three-relaunch budget.
5. Outcomes: gem_cycle_complete (confirmed deliberate loss plus gem reward), early_defeat (unplanned loss before the target), unverified_reward (result but no defensible gem amount), unexpected_victory, game_failure, user_stop, setup_or_safety_stop. Only gem_cycle_complete increments completed gem cycles and total verified gems. Treat a post-wave-29 loss with unreadable credit as unverified_reward, not a success.
6. 1.5× speed option is hidden or visibly disabled until normal mode is accepted and current client/ticket UI is verified. A checked setting alone is not proof speed activated; require the observed indicator after ticket consumption, and never purchase currency/items. If 1.5× changes tower timing or skip behavior, require new live proof rather than reusing 1× evidence.

## Stage-by-stage script: source-of-truth requirements

Names: F1–F8 are Farms, B1–B5 Boomerangs, C1–C5 regular Crook Bosses, X1 optional EXP tower. These IDs represent independently placed towers in a typed ledger, **not** game hotbar keys or coordinates.

| Wave window | Actions in priority/dependency order | Required stage state |
|---|---|---|
| 1–4 | Place F1–F4; upgrade F1–F3 to level 2; F4 level 1 | Four Farms, levels 2/2/2/1 |
| 5 | Place B1 and upgrade to level 1; F4 to level 2 | Four L2 Farms and B1 L1 |
| 6 | B1 to level 2; place F5 and upgrade to level 2 | Five L2 Farms, B1 L2 |
| 7–9 | Upgrade F1–F5 to level 3 | Five L3 Farms |
| 10 | Upgrade B1 to level 3 (Lead detection) | B1 L3 |
| 11 | Place F6 and F7; upgrade each to level 3 | Seven L3 Farms |
| 12–13 | Place C1 and upgrade to L2 (Hidden detection); place F8 and upgrade to L3 | Eight L3 Farms; C1 L2 |
| 14–15 | Check all eight Farm IDs and levels; do not place duplicates | Exactly eight L3 Farms |
| 16 | Place B2, upgrade to L3; place C2, upgrade to L2 | B1/B2 L3; C1/C2 L2 |
| 17–18 | Place B3, B4, B5 and upgrade each to L3 | Five L3 Boomerangs |
| 19–21 | Place C3, C4, C5 and upgrade each to L2 | Five L2 Crook Bosses |
| 22 | If enabled and eligible, place X1 from slot 4 once, preferably back half near exit | Optional placement confirmed, or recorded skip |
| 23–28 | Upgrade any two selected Crook Bosses to L3 for Tommy Goons; upgrade B1–B5 to maximum L4 if income permits | Two L3 Crook Bosses; target five L4 Boomerangs |
| On verified wave 29 | Freeze purchase/upgrade scheduler. Guardedly select and sell defending towers one by one; include optional fighting X1 and Farms only when justified | No further combat purchasing; each sale count/identity confirmed |
| 29–30 end | Observe actual base depletion, result state, Hardcore/Wretched Front/wave metadata and credited gems; replay via verified supported route | gem_cycle_complete only with positive reward verification |

**Within a wave window:** a wave window is an earliest-to-latest target, not a blind burst of clicks. Use current on-screen wave, actual cash, price, selection identity, prerequisite state, tower count and target visibility for every action. Recommended priority: avoid leaks / obtain first Crook Boss L2 in time for Hidden > essential Boomerang damage/Lead > remaining required economy > optional EXP > extra max upgrades. If affordability or wave advancement makes an essential stage impossible, stop safely or record a strategic failure rather than replaying expired actions. Do not change the supplied wave plan merely to improve modeled yield without measuring real results.

**Selling:** wait for at least two positive wave-29 observations and validated normal gameplay state. Sell selected Boomerangs and Crook Bosses first (and any combat X1) to enable leakage; selling Farms is not necessary for damage removal but may be required to ensure selected state/count returns to a known value. Observe result screens before every sell, verify the selected tower and actual sale control, make exactly one sale and require count decrement/tower disappearance. Goons may persist after selling; do not infer immediate death.
