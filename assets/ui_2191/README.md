# Recognition assets

Cropped English TDS v2.19.1 UI observed 14–15 November 2026 at physical 1920×991/120 DPI. Account names, chat and player lists are excluded. Independent sanitized test frames cover actual animation, hover, perspective and decoration failures.

The manifest requires multiple anchors per state. Map-vote state does not establish map identity; inventory state does not establish Golden status/slot. Separate checks confirm these. HUD count fractions include the denominator; identity does not use skin portraits.
