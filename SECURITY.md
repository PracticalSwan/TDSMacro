# Security

Use [private GitHub vulnerability reporting](https://github.com/PracticalSwan/tds-macro/security/advisories/new) for security defects. Include version, minimal reproduction, expected boundary and impact. Do not include account secrets or full private captures.

Only the latest release receives fixes. No Roblox credentials are needed. Strategies are parsed data; input is ordinary foreground-guarded OS input. Report parsing/path escapes, stop/focus bypasses, private-data exposure or repeated uncertain purchases privately.

Redacted gameplay/UI suggestions belong in the public suggestion form. Do not publicly disclose exploit details or attach executables. No guaranteed response time or bounty is offered.
